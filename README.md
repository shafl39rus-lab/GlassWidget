# GlassWidget

Русскоязычный виджет для Android 12–16. На лаунчерах, включая OxygenOS, доступный размер зависит от сетки домашнего экрана. Добавьте виджет через настройки приложения или меню виджетов лаунчера и растяните его до нужного размера.

## Установка с телефона

1. Откройте вкладку **Actions** репозитория в браузере, войдите в GitHub и выберите последний успешный запуск **Сборка APK**.
2. В разделе **Artifacts** скачайте **GlassWidget-APK**. GitHub выдаёт ZIP с файлом `GlassWidget.apk`.
3. Распакуйте ZIP в файловом менеджере и откройте APK. Если Android запросит разрешение установки из этого источника, выдайте его файловому менеджеру и вернитесь к установке.
4. Откройте GlassWidget и добавьте виджет.

Сборки используются с отладочной подписью. Если свежий APK подписан другим ключом, Android потребует удалить предыдущую сборку перед установкой. Это удалит сохранённые настройки и баланс.

## Источники данных

- Календарь читает видимые календари Android после выдачи разрешения. Нажмите на карточку для списка событий текущего месяца.
- Прогноз на семь дней загружается через Open-Meteo. При ошибке виджет покажет её рядом с датой сохранённого прогноза, если он есть. Android может отложить фоновое обновление до появления сети или выхода из режима энергосбережения.
- Шаги считаются с момента включения подсчёта. Нужен датчик шагов и разрешение на физическую активность. После перезапуска телефона откройте настройки и включите подсчёт снова. Часть шагов на границе суток или во время остановки службы может отсутствовать. На OxygenOS ограничение фоновой работы может остановить подсчёт.
- Заряд читается из Android.
- Карточка Билайн открывает приложение `ru.beeline.services`. Баланс вносится вручную в настройках и сохраняется локально вместе с датой. Автоматическое чтение требует публичного интерфейса оператора.

## Сборка

Для локальной сборки нужны JDK 17 и Android SDK 36.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```
